# 第02课：市场结构识字（阶段1 · 只看不做）

> 前置：已完成第01课（概率思维、交易者方程式、风险第一）。
> 本课目标：打开任何一张K线图，指着任意位置，能在30秒内回答两个问题——
> **① 现在是趋势还是区间？② 如果被逼着持仓，我做多还是做空？**
> 本阶段纪律：**只看，不做。** 不开模拟单，不开实盘单，连"如果我刚才进了就赚了"这种复盘都不许有仓位视角。你现在是在学认字，不是在学写作文。

## 一、市场只有两种状态

任何时刻、任何品种、任何周期的图，都处于两种状态之一：

- **趋势（trend）**：价格持续朝一个方向移动，买卖双方有一方明显占优。
- **区间（trading range）**：价格在一个大致水平的带状范围内来回震荡，双方僵持。

**突破（breakout）不是第三种状态**，它是两种状态之间的过渡动作：区间被打破变成趋势，或趋势结束后开始横盘变成区间。突破本身持续时间很短——几根K线而已。

三个必须刻进脑子的统计事实（布鲁克斯反复强调）：

1. **市场约80%的时间处于区间**，只有约20%的时间在趋势中。
2. **区间内的突破大多数会失败**——价格冲出区间边缘，然后被打回来。区间的本质就是"突破失败制造机"。
3. 因此，**看图的第一个动作永远是判断状态，而不是找进场点**。在区间里用趋势打法（追突破）会被反复打脸；在趋势里用区间打法（逆势高抛低吸）会被碾过去。状态判断错了，后面所有分析都是错的。

这就是第01课交易者方程式的直接应用：同一个形态，在趋势里可能胜率60%，在区间里可能只有30%。**背景（状态）决定概率。**

## 二、趋势长什么样

### 多头趋势（bull trend）：高点抬高 + 低点抬高（HH/HL）

用文字描述一段典型的多头趋势：价格先涨一段，形成一个波段高点（swing high）；然后回落，但**跌不回上一个波段低点**就止跌了，形成一个更高的低点（Higher Low, HL）；接着再涨，**涨过上一个波段高点**，形成更高的高点（Higher High, HH）。如此重复：HH → HL → 更高的HH → 更高的HL。整体像上楼梯：每一级台阶都比上一级高，回撤只是台阶之间的踏步。

强多头趋势在图上的样子：连续多根阳线（收盘价高于开盘价的K线），每根的收盘价高于前一根的最高价，K线实体饱满、上下影线短，中间偶尔夹一两根小阴线，但这些阴线的低点很快被下一根阳线的上涨吞掉，回调深度不超过前一根阳线实体的一半。

### 空头趋势（bear trend）：低点降低 + 高点降低（LL/LH）

完全镜像：价格跌出一个波段低点，反弹但**弹不回上一个波段高点**就掉头（Lower High, LH），再跌破前低（Lower Low, LL）。像下楼梯：LL → LH → 更低的LL → 更低的LH。强空头趋势就是连续阴线、每根收盘低于前一根最低价、反弹弱而短。

### 判断方法

在图上从右往左找最近的三四个波段转折点（那些明显的"山峰"和"山谷"），比较它们的相对高度：

- 峰比峰高、谷比谷高 → 多头趋势
- 峰比峰低、谷比谷低 → 空头趋势
- 峰谷高度乱七八糟、大致在一个水平带内 → 区间

## 三、Always-in：被逼持仓，你站哪边？

这是布鲁克斯最实用的思维工具。**任何一根K线走完，你都必须能回答：**

> "如果现在有人拿枪逼着我必须持仓，且只能选多或空，我选哪边？"

- 答案是做多 → 市场处于 **always-in long**（始终在多）
- 答案是做空 → 市场处于 **always-in short**（始终在空）

注意：这不是让你真的去持仓（本阶段禁止），而是强迫你对多空力量对比表态，消灭"看不清就不表态"的模糊地带。区间里也有答案——只是答案的把握度低，且可能几根K线就翻转一次。

**三个判断依据（按重要性排序）：**

1. **最近一次强突破的方向。** 往回看：最近一次"连续多根同色大实体K线、几乎无回调地穿过前期波段高/低点"的运动，是向上还是向下？向上突破且之后没有被反向同等力度的运动否定 → always-in long。强突破是市场最诚实的表态。
2. **近期K线主体的位置和颜色。** 最近10-20根K线，实体大多是阳线还是阴线？收盘价是不断上移还是下移？多数K线收在自身区间的上半部还是下半部？
3. **价格与20 EMA的位置关系。** 价格持续运行在EMA上方 → 偏always-in long；持续在下方 → 偏always-in short（EMA下一节讲）。

三个依据指向一致时，方向明确、把握大；互相矛盾时（比如价格在EMA上方但最近三根是大阴线），说明市场正在争夺，此时你的答案要伴随一句"但把握不大"——这本身就是有价值的判断，它告诉你现在的概率不清晰，第01课说过：**概率不清晰 = 期望值算不出来 = 不该有仓位。**

## 四、20 EMA：唯一需要的均线

布鲁克斯的图上只有一条指标线：**20周期指数移动平均线（20 EMA）**。它是最近约20根K线收盘价的加权平均（越近的K线权重越大），在图上表现为一条跟随价格的平滑曲线。现在去你的交易软件里把它加上，颜色调醒目，其他所有指标全部删掉。

它不是魔法线，而是一把**状态标尺**：

- **多头趋势中**：价格大部分时间运行在EMA**上方**，EMA本身向上倾斜。价格回调（pullback）时常常跌到EMA附近就止跌回升——图上看就是：一串阳线远离EMA，然后两三根小阴线向下靠近EMA，K线的低点触到或稍微刺穿EMA，随后出现阳线重新向上。这叫"EMA支撑"。
- **空头趋势中**：镜像。价格大部分时间在EMA**下方**，EMA向下倾斜，反弹到EMA附近常被压回去。
- **区间中**：EMA走平（近似水平），价格**反复上下穿越它**——这根K线收在上方，过三根又收在下方，EMA像一条被来回踩的绳子。

**快速读法**：只看两个东西——EMA的**斜率**（明显向上/向下/走平）和价格在EMA**哪一侧待得久**。斜率清晰+价格单侧运行 = 趋势；斜率走平+反复穿越 = 区间。这个读法5秒钟完成，是你判断状态的第一道粗筛。

## 五、逐根K线阅读（bar-by-bar）入门

结构是由一根根K线垒出来的。每根K线走完，问它三个问题：

**1. 它收在上一根的哪里？**

- 收盘价高于上一根的**最高价** → 多方明确胜了这一局，强多头信号。
- 收盘价低于上一根的**最低价** → 空方明确胜了。
- 收盘价在上一根的高低点**之间** → 这一局没分胜负，市场在犹豫。连续多根这样互相重叠的K线，就是区间的微观形态。

**2. 实体说明什么？**

实体 = 开盘价与收盘价之间的部分，代表这根K线时间内**净战果**。大实体阳线（实体占整根K线三分之二以上，收盘接近最高价）= 多方从头压着打；大实体阴线镜像。小实体（十字星样，开盘收盘几乎相同）= 打了个平手，双方力量接近。

**3. 影线说明什么？**

影线 = 实体上下伸出的细线，代表**去过但没守住的价格**。长上影线（K线冲高很多但收盘掉回来）= 多方发起进攻被空方打退，上方有抛压。长下影线 = 空方压低被多方买回来，下方有买盘。**影线是失败的进攻。** 区间里影线普遍很长很多；强趋势里影线短、实体大。

入门阶段记一个总原则：**趋势 = 连续性**（K线同方向、收盘不断突破前根极值、实体大影线短）；**区间 = 重叠性**（K线互相咬合、收盘在前根范围内、影线长实体小、颜色交替）。

## 六、区间的特征与"中间地带禁区"

区间在图上的完整画像：

- K线之间**大量重叠**，每根K线的范围与前一根有一半以上交叠；
- **上下影线多而长**，说明每次冲高、探低都被打回；
- **颜色反复交替**，两三根阳线接两三根阴线，谁也走不远；
- **20 EMA走平**，价格像缝纫机针一样反复穿越它；
- 试图冲出区间上沿或下沿的动作（突破）**大多在一两根K线内失败**，收回区间内部。

区间有三个地带：**上沿附近、下沿附近、中间地带**。将来你学到区间打法时会知道：只有在上沿附近考虑做空、下沿附近考虑做多才有正期望——因为价格从边缘回到中间的概率高。而**中间地带是禁区**：价格在区间正中间时，向上向下的概率接近五五开，胜率约50%、盈亏比也不占优——套进交易者方程式，期望值约等于零再减去手续费，是负的。**在区间中间做任何方向的交易，都是给市场交学费。** 本阶段你不交易，但从现在起养成条件反射：看到价格在区间中部，脑子里自动亮红灯——"此处无期望值"。

## 七、常见识别错误

1. **把区间里的两三根同向K线当成趋势。** 两三根阳线不构成多头趋势，趋势需要结构（HH/HL）支撑。先看波段高低点，再下结论。
2. **把趋势中的正常回调当成反转。** 多头趋势里出现两三根阴线就喊"转空了"——只要回调没跌破上一个波段低点（HL没被破坏），趋势结构完好，always-in仍是long。
3. **用一根K线否定整个背景。** 一根大阴线出现在强多头趋势里，大概率只是回调的开始，不是趋势终结。单根K线的权重永远小于结构。
4. **忘了看EMA斜率，只看价格位置。** 价格在EMA上方但EMA已走平、价格反复穿越——这是区间，不是多头趋势。
5. **不敢给答案。** "看不清"说三次以上就是逃避。Always-in练习的意义就是强迫表态，答错了改，不表态永远不会进步。
6. **放大镜病。** 盯着最近5根K线纠结，忘了缩小图表看最近100根的大结构。判断状态永远先看全景再看局部。

## 八、自测复述题

用自己的话回答（写下来，别在脑子里糊弄过去）：

1. 市场的两种状态是什么？突破是什么？市场大约多少时间在区间？区间内的突破通常什么下场？
2. 多头趋势的结构定义是什么（用HH/HL说清）？空头趋势呢？
3. Always-in问题的原始表述是什么？判断always-in方向的三个依据是什么？三个依据互相矛盾时说明什么？
4. 20 EMA在多头趋势、空头趋势、区间中分别与价格是什么关系？"5秒读法"看哪两个东西？
5. 一根K线收在上一根最高价之上说明什么？长上影线说明什么？
6. 区间的五个图形特征是什么？为什么区间中间地带不能交易（用交易者方程式解释）？

全部能脱口而出且解释得清，才算过关。

## 九、看图练习任务（每日执行）

**准备**：打开交易软件，任选一个流动性好的品种（大盘指数、主流外汇对或大市值股票均可），周期先固定用5分钟图，图上只保留20 EMA，删掉其他所有指标。

**每天的练习流程（约20分钟）：**

1. 随机翻到历史图上任意一天（不要用今天的图，避免结果诱惑），把图定格在某个位置，只看左边、不看右边。
2. 对定格位置回答并**写下来**：
   - 当前是趋势还是区间？依据是什么（波段高低点结构、K线重叠度、EMA斜率与穿越情况）？
   - Always-in哪边？三个依据分别指向哪里？把握大还是小？
3. 然后向右播放20-30根K线，检验判断。判断错了，写下错在哪一条依据上。
4. 每天至少做3个不同位置，把其中1个的完整判断过程用文字描述给教练（我），格式："图上我看到……（描述波段结构、K线形态、EMA关系），所以我判断……，播放后实际……"。我来纠正你的读图偏差。
5. 每周额外做一次"缩放练习"：同一个位置，分别在5分钟和1小时周期上判断状态，体会不同周期可以同时处于不同状态（5分钟趋势可能只是1小时区间里的一段）。

## 十、出关标准

同时满足以下三条，才进入第03课：

1. 累计完成**至少15个位置**的书面判断记录；
2. 最近连续10个判断中，趋势/区间状态判断和播放后的实际走势**至少7个吻合**，且每个判断都写出了明确依据（蒙对的不算）；
3. 向教练描述任意一段图形时，能连贯使用本课术语（HH/HL、always-in、EMA斜率、K线重叠），教练追问"依据是什么"时不卡壳。

## 最后的纪律提醒

本阶段的身份是**观察者，不是交易者**。练习中看到"完美的进场机会"而心痒，是必然会发生的事——把它记录下来当作心态素材，但**任何形式的进场（包括模拟单）都是违规**。你还没学信号K线、没学止损、没学仓位，此时进场等于进场、止损、出场三者只确定了一个——第01课说过，那不是交易，是赌博。识字没完成的人不许写作文。

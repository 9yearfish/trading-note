# 第06课：理由叠加与进场检查表（阶段5）

> 前置：01-05课已出关。本课把前五课全部串成一个决策流程。
> 你当初就是被一句话吸引来的："入场不是一个理由，而是理由的叠加。"这一课就是兑现这句话。

## 课程目标

学完本课，你要能做到：

1. 说清什么是有效的理由叠加（confluence），什么是自欺式的重复计数。
2. 对任意一笔候选交易，实时逐项过完七项检查表并打钩。
3. 用打钩数量估胜率、量出止损与目标距离、套交易者方程式，得出"做/不做"的结论。
4. 识别"事后拟合"陷阱，明白检查表只在**事前**有意义。

## 一、理由叠加的正确理解

### 1.1 什么叫叠加

单独一个 High 2 回调，胜率大约55%——比抛硬币好一点，但扣掉止损通常比目标远的现实，优势很薄。理由叠加（confluence）的意思是：**多个互相独立的证据，同时指向同一个方向**。趋势结构说涨、位置说这里该有买盘、信号K线（signal bar）说买方刚赢了这根、日线说大资金也在买——四个不同来源的证据同向，这笔交易的胜率才可能从55%抬到65-70%。

注意两个关键词：

**独立。** 证据必须来自不同维度才能叠加。"这根阳线实体大"和"这根阳线收在最高点附近"是同一个证据（信号K线强）的两种说法，写成两条理由是重复计数，是自欺。你在骗自己"我有五个理由"，实际只有两个。七项检查表的七个维度就是七个独立信息来源：背景、位置、回调结构、信号K线、对手强弱、跟随、大级别——它们可以各自独立地成立或不成立，所以才有资格分开打钩。

**概率，不是确定。** 叠加把胜率从55%提到65-70%，仅此而已。七项全勾的交易照样会亏，而且会经常亏——70%胜率意味着十笔里三笔是输的，连输三笔在数学上稀松平常。这里立一条纪律：**"这笔肯定涨"是危险措辞。** 只要你脑子里冒出"确定""必然""稳了"这类词，就是在关掉风险开关，接下来通常是重仓和不设止损。正确的措辞永远是："这笔大约65%的概率到目标，35%的概率打止损，期望值为正，所以做，并且做错了认赔。"

### 1.2 叠加为什么有效

回到01课的交易者方程式：`胜率 × 盈利 > (1−胜率) × 亏损`。胜率每提高10个百分点，同样盈亏比下期望值大幅改善。叠加不改变形态本身，改变的是这个形态**出现的语境**——同一个 High 2，出现在强趋势回踩20EMA处，和出现在区间中央，是两笔完全不同的交易。检查表就是把"语境"拆成可核对的七个问题。

## 二、七项进场检查表（多头版）

每项给出判断标准。判断标准全部来自02-05课，这里是汇总，不是新知识。

### ① 趋势背景（context）

**问：市场现在是多头趋势吗？**
打钩标准（三条至少占两条）：

- 结构上是 HH/HL：高点抬高、低点抬高，最近一个摆动低点没有被跌破。
- 价格在20EMA上方运行，EMA向上倾斜，多数K线不触碰EMA或只短暂触碰。
- 前期的阳线有好跟随（follow-through）：大阳线之后紧跟的K线继续收阳或至少不吞回，说明买方推动后没人反抗。

示例：过去30根K线里，价格三次创新高，两次回调都止于前高上方，20EMA下方几乎没有收盘价。✔

### ② 位置（location）

**问：价格现在处在"应该有买盘出现"的位置吗？**
以下任占其一即可打钩：

- 回踩20EMA附近（趋势中第一、二次回踩最可靠）。
- 突破点回测：之前向上突破的那个平台/前高，现在从上方踩回来。
- 趋势线或通道下轨附近。
- 测量移动（measured move）目标位附近的回调（第一段涨幅的投影位）。
- 回调落在前摆动高点上：原来的阻力翻为支撑。

位置的本质是"这里有前期被套的空头要认输、有踏空的多头要补票"。在半空中（离任何参考位都远）出现的信号，位置项不打钩。

### ③ 回调结构（setup）

**问：回调本身走出了04课教的高概率结构吗？**

- High 2：回调中第二次向上尝试（第一次尝试失败后再来一次）。
- 两腿回调 / ABC：下-弹-下两段式，第二腿结束处。
- 第二次尝试：第一个突破回调进场失败后，市场很快再给的第二次机会。

只有"跌下来了"不算结构。必须能指着图说出"这是第几腿、这是 High 几"。

### ④ 信号K线质量（signal bar）

**问：扣扳机的这根K线，本身是强K线吗？**

- 阳线实体大（实体占整根K线的大半）。
- 收盘价在最高点附近（收在顶部三分之一以内）。
- 上影线小，下影线可以有（下影线代表买方把低位收复了）。

示例：回调第五根，出现一根实体饱满、收盘几乎就是最高价的阳线——买方在这根K线里明确赢了。✔ 反例：十字星、长上影线的阳线，信号项不打钩。

### ⑤ 对手无力

**问：这波回调里，卖方表现出实力了吗？**
卖方**无力**的证据（越多越好）：

- 回调的阴线互相重叠严重，没有走出流畅的下跌。
- 阴线实体小，十字星多。
- 阴线带下影线（每次下探都被买回一截）。
- 阴线没有跟随：一根稍大的阴线之后，下一根不再创新低。

回调= 卖方的进攻。进攻绵软无力，才值得逆着这波回调做多。如果回调是连续大实体阴线、收盘都在最低附近，那不是回调，可能是反转，此项不打钩且要警惕①是否还成立。

### ⑥ 进场后跟随确认（follow-through）

**问：进场触发后，市场立刻按剧本走了吗？**
这一项在进场那一刻打不了钩，它是**进场后第一时间的复核**：突破信号K线高点成交后，下一根K线应该是阳线或至少不深跌回信号K线内部。有跟随→ 持有甚至按计划加码；无跟随（立刻缩回、变成十字星）→ 警觉，考虑按05课规则减仓或提前离场。它提醒你：进场不是决策的结束，是管理的开始。

### ⑦ 大级别同向

**问：上一级周期站在你这边吗？**
你做5分钟图，就看小时/日线；做日线，就看周线。打钩标准：大级别本身是多头趋势，或者大级别正回踩到明显支撑（日线20EMA、周线前高）。大级别同向时，你的小级别趋势更不容易被突然的反向大波动打断。大级别明确空头时，小级别做多最多是逆势抢反弹——此项不打钩，且整笔交易要按"胜率下修"处理。

## 三、打钩规则：几个勾才值得做

原理很简单：**勾越多，独立证据越多，胜率越高。** 大致的经验映射（不是精确科学，是量级感）：

| 打钩数 | 胜率量级 | 态度 |
|--------|----------|------|
| 7/7 | ~70% | 罕见，出现就是全仓规则内的重点交易 |
| 5-6/7 | 60-65% | 正常的好交易，这是你该做的主体 |
| 4/7 | ~55% | 边缘，只有盈亏比特别好才考虑 |
| ≤3/7 | ≤50% | 不做，没有讨论余地 |

操作门槛建议（写进你的交易计划）：

> **至少5/7才考虑进场，且①趋势背景、②位置、③回调结构三项必须全部在内。**
> 理由：①②③是"这笔交易存在的前提"，④⑤⑥⑦是"执行质量加分项"。前提缺一项，后面勾再多也是在错误的地方做正确的动作。

**反向警告：不要等8个勾。** 确认越多，进场越晚，止损距离越远、剩余的利润空间越小——胜率上去了，盈亏比下来了。等"万无一失"的人，最后进在趋势的最后一段。所以打钩不是最终裁决，**交易者方程式才是**：勾完之后，必须量出止损距离和目标距离，算 `胜率 × 目标距离 > (1−胜率) × 止损距离` 是否成立。检查表管胜率，方程式管值不值。

## 四、完整决策流程演示

### 例一：5个勾，期望值为正 → 做

虚构行情（5分钟图，某指数期货）：

1. **趋势判断**：上午开盘后一路走高，两个HH两个HL，20EMA向上，价格全程在其上方，中途两根大阳线各自都有跟随。→ **① ✔**
2. **回调观察**：第二波上涨后开始回调，五根K线，跌到20EMA附近，同时这里恰好是上一个摆动高点（前高翻支撑）。→ **② ✔**
3. **回调结构**：回调中第三根曾试图上攻失败（High 1），现在第五根再次上攻——这是 High 2。→ **③ ✔**
4. **信号K线**：第五根收出中等实体阳线，但上影线不小，收盘在整根的上部但不算贴顶。→ **④ ✘**（质量平庸，不给勾）
5. **对手力量**：回调的四根阴线全部实体小、互相重叠、其中两根带明显下影线。卖方无力。→ **⑤ ✔**
6. **大级别**：日线是多头趋势，且今天正回踩日线20EMA后收复。→ **⑦ ✔**
7. ⑥进场后跟随属于事后复核，进场时不计。

**计数：5/7（①②③⑤⑦），且①②③齐备 → 过门槛。**

**算账**：信号K线高点上方1跳挂买入止损单，进场价4001；止损放信号K线低点下方1跳，3993，**止损距离8点**；目标看测量移动：第一段涨幅16点，从回调低点投影，目标4009，**目标距离8点**，盈亏比1:1。

**套方程式**：估胜率65%（5个勾的量级）。`0.65 × 8 = 5.2 > 0.35 × 8 = 2.8`。期望值 = +2.4点/笔。**结论：做。** 成交后下一根K线收中阳、创新高——⑥跟随确认，按05课规则持有到目标。

注意：这笔交易信号K线平庸（④没勾），依然值得做——因为其他独立证据足够强，且方程式为正。检查表不要求完美，要求够数。

### 例二：3个勾 → 放弃

同一天下午：

1. 午后价格横住了：最近的一个高点没有超过前高（没有HH），价格反复穿越20EMA，EMA走平。→ **① ✘**（这已经是区间，不是趋势）
2. 价格跌到中午的一个小平台附近，勉强算突破回测。→ **② ✔**
3. 回调走了两腿，形态上是个ABC。→ **③ ✔**
4. 信号K线是根长下影小实体的阳线，收盘在中部。→ **④ ✘**
5. 回调中的阴线有两根实体不小、收盘接近最低。卖方并不弱。→ **⑤ ✘**
6. 日线仍是多头。→ **⑦ ✔**

**计数：3/7，且①缺失 → 直接放弃，连方程式都不用算。**

这正是检查表的价值所在：这笔交易"看起来也有ABC、也在支撑位、日线也向上"——单独讲每条理由都成立，讲给别人听甚至像个好故事。但趋势背景没了，对手不弱，信号绵软。三个勾的交易，做一百笔就亏一百笔的期望值。检查表让你在有故事可讲的时候，仍然看得见数不够。

## 五、反面教材：事后拟合的危险

打开任何历史图，找到任何一段上涨，你都能在起点处"发现"五个理由：这里是前高支撑、这里是 High 2、这根是强阳线、日线也向上……**任何人都能给已经涨了的行情写出完美的叠加故事。** 这叫事后拟合（curve fitting / hindsight bias）：你先知道了答案，再回头挑证据。

事后拟合的危害不是浪费时间，是它会给你虚假的胜率认知——你在历史图上"验证"出80%胜率，实盘却只有50%，因为实时状态下右侧K线不存在，一半的"理由"你当时根本看不清、或者会看反。

检查表的意义因此只有一个：**实时、事前，在右侧还是空白的时候，强迫你逐项回答，并把答案写下来。** 写下来的那张表，才是可以事后统计、可以证伪的记录。事后讲故事的复盘，一律无效。这也是07课交易日志的地基：每笔交易先有表，后有单。

## 八、常见错误

1. **重复计数**：把同一证据换个说法多打一个勾（"阳线实体大"+"收盘在高位"= 一个勾，不是两个）。
2. **用"确定"替代"概率"**：七个勾也只是70%，说出"稳了"两个字就该警惕自己。
3. **等待过多确认**：追求7/7，结果进场太晚，止损被迫放远，盈亏比恶化。忘了方程式才是裁判。
4. **①②③缺项硬做**：信号K线漂亮就冲进去，不管背景是区间——在错误的地方做正确的动作。
5. **事后拟合**：用已知结果的历史图给自己"验证"高胜率，实盘幻灭。
6. **打完钩不算账**：检查表只解决胜率端，不量止损/目标距离就下单，等于只做了半个决策。
7. **⑥不复核**：进场后无跟随却死拿，把"进场理由消失"的单子拿成大亏损（回看05课）。

## 十、实战练习（提交验证）

在你自己的交易软件上，**用逐根播放/遮住右侧的方式**（禁止看着完整走势倒推）：

1. 找5笔候选交易（至少含1笔空头）。
2. 每笔填一张上面的空白检查表：逐项写出当时看到的证据、打钩、数勾。
3. 对≥5勾的：标出进场价、止损价、目标价，算盈亏比和期望值，写"做/不做"。
4. 对<5勾的：写清缺哪几项、为什么放弃。
5. 然后才允许播放右侧，记录实际结果与你判断的偏差。
6. 把5张表连同截图描述提交给我，我逐项验证你的打钩是否成立——重点抓重复计数和事后拟合。

- 对任意一笔候选交易，能实时完整打钩、说清每个勾的证据来源，并当场算出期望值、给出"做/不做"。
- 5张练习表中，打钩经教练验证无重复计数、无事后拟合，期望值计算无误。

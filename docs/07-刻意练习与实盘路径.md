# 第07课 刻意练习与实盘路径

> 阶段6 · 从知识到技能的桥梁。这是全部课程里**时间最长、也最重要**的一课。
> 前置：01-06 全部通过复述。本课学完后，你的主要工作不再是"学新东西"，而是"跑样本"。

---

## 课程目标

1. 理解为什么价格行为是**视觉+执行技能**而非知识，以及为什么这决定了本阶段不可跳过。
2. 掌握布鲁克斯式的历史图逐根复盘法（bar-by-bar replay），并能独立执行。
3. 建立自己的交易日志（trading journal）和 50 笔样本块统计（sample block），会算期望值（expectancy）和违规率。
4. 记住三级晋级路径（L1 复盘 → L2 模拟 → L3 实盘）的全部铁律，包括降级规则。
5. 学会用"决策质量 vs 结果"双维度给每笔交易打分，根治结果导向。

---

## 一、核心观念：你现在拥有的是知识，不是技能

先把话说透：**看懂 01-06 课的概念，只需要几周。而 95% 的人依然亏钱。**

差在哪？不在知识，在执行。这正是总大纲核心信条第 5 条：真正的优势不在形态，在执行。

价格行为学本质上是两种能力的叠加：

- **视觉技能**：在 K 线还在生成、右侧一片空白时，实时认出"这是 High 2、这是突破失败、always-in 已翻空"。这和认出概念图上画好的形态，是两回事——就像看懂棋谱和实战下棋的区别。
- **执行技能**：认出来之后，按计划下单、按计划止损、按计划持有到目标，不因为恐惧提前跑、不因为贪心挪止损。

这两种技能都只能靠**大样本重复**获得。你作为 CEO 应该秒懂这个逻辑：一个方法有正期望值（positive expectancy），和**你这个人**能把这个正期望值兑现出来，是两个完全不同的命题。前六课解决了前者，本课解决后者。

**本阶段的唯一目的：用大样本数据证明"你的执行能兑现方法的正期望值"。证明拿到之前，不许动用任何有意义的资金。** 这不是建议，是铁律（总大纲学习节奏规则最后一条）。

为什么必须是大样本？回到第 01 课：单笔无意义。一个胜率 55% 的方法，连亏 5 笔的概率约 1.8%——跑 100 笔几乎必然遇到。样本量（sample size）不够时，你根本分不清"方法失效"和"正常波动"，也分不清"我有能力"和"我运气好"。50 笔是能开始说话的最小单位，几百笔才有结论。

## 二、历史图逐根复盘法（bar-by-bar replay）

这是布鲁克斯本人反复强调的训练方式：他自己就是靠打印历史图、一根一根遮着看，练出实时读图能力的。原理很简单——**把"事后看图"变成"实时看图"的模拟**。看完整的历史图人人都是股神，因为右侧答案全摆在那；遮住右侧，你才知道自己到底会不会。

### 具体操作步骤

1. **选图**：打开你交易软件的历史图（用你将来真要交易的品种和周期，比如 5 分钟图），拉到某一个交易日的开头。
2. **遮住右侧**：用软件的回放（replay/bar replay）功能；没有就把窗口拖到只显示到当前 K 线，或干脆拿纸挡住屏幕右侧。关键是**绝对看不到下一根**。
3. **逐根推进，每根 K 线笔头回答三个问题**：
   - ① 现在 always-in 哪边？（多 / 空 / 不确定——用第 02 课的判断法）
   - ② 有没有 setup 正在形成？是什么？（用第 04 课的命名：High 2、突破回调、区间高抛……）
   - ③ 如果这根触发进场，止损放哪、目标在哪、盈亏比多少？（用第 05 课的规则）
4. **写下来，再推进下一根**，用后续走势验证自己刚才的判断。错了就标注错在哪：是没看出结构，还是理由不够就想动手？
5. 一天推完，用第 06 课检查表回看：今天图上真正值得做的交易有几笔？我在当时那根 K 线上认出来了吗？

### 训练量要求

- **每天 30-60 分钟**，雷打不动。比一次练 4 小时然后歇一周有效得多——视觉技能和健身一样靠频率。
- 一次完整推演一个交易日 ≈ 一次复盘。**目标：累计几百次。L1 出关的底线是 200 次。**
- 关键纪律：写下来再看答案。只在脑子里过，你的大脑会自动作弊（后面自欺清单会讲）。

## 三、交易日志：每一笔都要留下完整证据

从 L2 模拟期开始，**每一笔交易（含模拟笔）都必须记日志**，无一例外。日志不是备忘录，是你向自己出示的证据链——将来允不允许你上实盘、加仓位，全看日志里的数字，不看你的感觉。

每笔必记字段：

- 日期、品种、周期
- 方向（多/空）
- **叠加了哪几项理由**：对照第 06 课检查表七项打钩——①背景 ②位置 ③结构 ④信号K线 ⑤对手无力 ⑥跟随 ⑦大级别。直接记编号，如"①②④⑥"。
- 进场价 / 止损价 / 目标价（进场前就写死，这是第 01 课信条第 3 条）
- 计划盈亏比
- 实际结果（盈亏金额或 R 倍数）
- **执行是否符合计划**——这是整个日志最重要的一列。任何计划外行为都记为**违规**：提前止盈、挪止损、没到 setup 就进场、该止损没止……**即使那笔赚了钱，违规就是违规。**
- 事后一句话复盘（只许一句，逼你抓要点）

## 四、统计口径：50 笔一个样本块

日志是原始数据，样本块是结论。**每满 50 笔，做一次统计**，指标固定如下：

| 指标 | 算法 |
|------|------|
| 胜率 W | 盈利笔数 ÷ 50 |
| 平均盈利 AW | 所有盈利单的平均盈利额 |
| 平均亏损 AL | 所有亏损单的平均亏损额（取正值） |
| **期望值 Expectancy** | `W × AW − (1−W) × AL`（就是第 01 课交易者方程式） |
| 最大连亏 | 样本内最长连续亏损笔数（校准心理承受与仓位） |
| 违规次数 / 违规率 | 违规笔数 ÷ 50 |

**过关标准（每个样本块独立判定）：期望值 > 0，且违规率 < 10%（50 笔中违规 ≤ 4 笔）。两条同时满足才算合格。**

为什么违规率单独设线？因为期望值为正但violations一堆，说明这 50 笔的正期望不是"你的系统"挣的，是"你的即兴发挥"挣的——即兴发挥不可复制，样本作废。

## 五、三级晋级路径与铁律

| 级别 | 名称 | 做什么 | 晋级条件 |
|------|------|--------|----------|
| **L1** | 复盘期 | 只做历史图逐根推演，**一单不下**（模拟单也不下） | 累计 ≥ 200 次逐根推演，且三个问题的答对率自评稳定提升 |
| **L2** | 模拟期 | 模拟盘，或最小可交易单位的微型实单；每笔记日志 | 累计 ≥ 100 笔（≥ 2 个样本块），**连续的样本块**期望值为正且违规率 < 10% |
| **L3** | 实盘期 | 真金白银，但从"**亏光也不心疼**"的资金规模起步；单笔风险 ≤ 总资金的 0.5%-1% | 连续两个 50 笔样本块合格，才允许加大资金规模；之后每次加大同理 |

三条补充铁律：

1. **不许跳级。** 没有任何理由可以从 L1 直接进 L3。"我以前炒过股""这段行情太明显了"都不是理由。
2. **L3 的起步资金必须满足"全亏光也不影响生活、不影响情绪"**。这不是矫情——第 09 课会讲，钱一旦"有意义"，恐惧和贪婪就会接管你的手，前面所有训练归零。
3. **降级规则（demote rule）：实盘中连续 20 笔滚动期望值转负，或违规率超过 10%，立即退回 L2 模拟期**，重新跑出一个合格样本块才能回来。降级不是惩罚，是刹车——公司业务连续恶化你也会先止血再复盘，同一个逻辑。

时间预期管好：L1 通常 2-4 个月（每天练），L2 至少 3-6 个月，到 L3 稳定加仓往往一年以上。**这是全课程时间最长的阶段，本来就该这么长。** 想压缩它的冲动，本身就是要被训练掉的东西。

## 六、好决策 ≠ 好结果

这是本课在思维层面最重要的一节。

概率游戏里，单笔的结果几乎不携带关于决策质量的信息：一笔七项打钩、盈亏比 2:1 的 High 2 交易被止损了——这是**好决策、坏结果**，完全正常，55% 胜率意味着 45% 的时候就是这样。反过来，一笔没有 setup 的冲动单赚了钱——这是**坏决策、好结果**，是市场发给你的毒糖果，它教你的坏习惯将来会十倍讨回去。

所以日志里每笔交易要打**两个独立的分**：

- **决策分**：进场时理由是否足够（对照 06 课检查表）、三要素是否进场前确定、执行是否符合计划。
- **结果分**：赚了还是亏了。

判定规则只有一条：**决策分说了算。好决策亏钱 = 合格的一笔；坏决策赚钱 = 违规的一笔，计入违规率。**

结果导向（resulting）是执行崩坏的万病之源：它让你在连亏后怀疑好系统、在侥幸赢钱后重复坏行为。你在经营公司时早就懂"不能用一个季度的运气评价一个战略"，把同样的纪律搬到图表上来。

## 八、晋级 / 降级规则速查表

| 动作 | 条件 |
|------|------|
| L1 → L2 | 逐根推演累计 ≥ 200 次 |
| L2 → L3 | ≥ 100 笔模拟，连续样本块期望值 > 0 且违规率 < 10% |
| L3 内加大资金 | 连续 **2 个** 50 笔样本块合格，每次加大后重新计数 |
| L3 → L2（降级） | 连续 20 笔滚动期望值转负，**或**违规率 > 10%，立即退回 |
| 降级后返回 L3 | 在模拟盘重新跑出 1 个合格样本块 |
| 任何情况下跳级 | **永远禁止** |

## 九、常见自欺行为清单

练习阶段最大的敌人不是市场，是自己给自己批准的作弊。逐条对照，中一条就说明数据已被污染：

1. **只记赢单**：亏损单"忘了记"或"那笔不算，是意外"。日志残缺 = 期望值造假 = 整个晋级体系失效。**每一笔都记，尤其是丢人的那笔。**
2. **后见之明（hindsight bias）**：复盘时看着完整图说"这个 High 2 我早就看出来了"。你没有。解药就是第二节的规矩——遮住右侧、先写下来、再看答案。白纸黑字不会陪你演。
3. **模拟盘乱下单**：反正不疼，就随手开仓试试。这不仅浪费样本，还在给"随意执行"刷肌肉记忆——你在花几个月的时间训练自己养成坏习惯。模拟盘每一笔必须当真金对待，否则模拟期数据对 L3 毫无预测力。
4. **跳级**：连赢几笔就觉得"我天赋异禀，200 次复盘是给普通人设计的"。小样本的连赢恰恰是最不携带信息的事件（第 01 课）。跳级的人不是省了时间，是把学费从模拟盘挪到了实盘交。
5. **用结果给决策洗地**：违规单赚钱后记成"灵活应变"。重申：坏决策赚钱 = 违规。
6. **偷偷放宽口径**：期望值差一点就把某笔亏损"重新归类"，违规 5 笔就说"其中一笔情有可原"。标准一旦可以商量，就不再是标准。

## 十、自测复述题

复述通过才算学完本课（用自己的话，不许背原文）：

1. 为什么"看懂概念"和"能赚钱"之间隔着几百次复盘？用"视觉技能 + 执行技能"解释。
2. 逐根复盘时每根 K 线要回答哪三个问题？为什么必须写下来而不是在脑子里过？
3. 期望值怎么算？为什么 50 笔是一个样本块，而不是 10 笔？
4. 违规的定义是什么？一笔赚了钱的计划外交易算不算违规？为什么违规率要独立于期望值单设一条线？
5. 完整背出 L1/L2/L3 的晋级条件和 L3 的降级规则。
6. 什么叫"好决策、坏结果"和"坏决策、好结果"？各举一个例子，并说明日志里分别怎么记。
7. 自欺清单六条，你自评最可能中哪一条？打算用什么机制防（不是"我会注意"，要机制）。

## 十一、出关标准

本课的出关标准，就是**晋级到 L3 的条件本身**：

> 1. 历史图逐根推演累计 ≥ 200 次，全程有书面复盘记录；
> 2. 模拟期 ≥ 100 笔完整日志，无缺笔；
> 3. 连续样本块：期望值 > 0，且违规率 < 10%；
> 4. 已确定"亏光也不心疼"的起步资金规模和单笔风险上限（≤ 0.5%-1%），并写进日志首页。

四条全部满足之前，**不许动用有意义的资金**。这一条没有例外，没有商量，也不因为你是谁而豁免。

下一课（08 高级概念）可以在跑样本的同时穿插学习；第 09 课（心态与纪律）的内容，会在你 L2/L3 的日志里反复被验证。

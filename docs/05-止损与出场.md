# 第05课 止损与出场 —— 交易管理（阶段4）

> 前置：已完成01（决策思维）、02（市场结构）、03（K线语言）、04（进场Setup）。
> 本课地位：**只会进场的人是给市场送钱的人。** 进场是整个交易里最容易的一步，出场才决定盈亏。

---

## 课程目标

学完本课，你必须做到三件事：

1. 对04课的**每一个setup**，能在进场前就说出：止损放哪、为什么放那、第一目标在哪、什么条件下持有到更远。
2. 能用公式 **仓位 = 可亏金额 ÷ 止损距离** 现场算出任何一笔交易的仓位。
3. 能完整管理一笔持仓：减仓、移动止损、识别趋势破坏、在买入高潮中主动离场。

## 开篇：三位一体，缺一即赌博

回到01课的交易者方程式：

```
期望值 = 胜率 × 平均盈利 − (1−胜率) × 平均亏损
```

注意方程式里的四个量：胜率、盈利、亏损。**"盈利"由出场目标决定，"亏损"由止损位置决定。** 如果你进场时这两个数不存在，方程式就无法计算——你不知道自己在做一笔期望值为正还是为负的交易。不知道期望值还下单，按定义就是赌博，跟形态画得多漂亮没有关系。

所以铁律是：**进场、止损、出场是同一个决策的三个面。三者在下单前必须全部确定。** 你不是"先买入再看情况"，你是在下单前就已经写好了这笔交易的完整剧本：在哪进、错了在哪认、对了在哪收。

## 第一部分：止损（Protective Stop）

### 1. 止损的本质：入场理由的证伪点

止损不是"我愿意亏多少钱"的心理承受线，也不是随手减去的固定点数。**止损 = 你的入场理由被证伪的价格。**

你在牛趋势回调买High 2，理由是"回调结束、趋势恢复"。如果价格跌破了整个回调的低点，回调没有结束、甚至趋势可能已反转——你的理由死了。理由死了，仓位就没有存在依据，无条件出场。

这里有一个思维校准：触发止损**不等于**做错了交易。一笔胜率60%的好交易，10次里有4次会打止损，这4次是成本，不是错误。真正的错误只有一种：理由已经被证伪，人还赖在场内。

### 2. 止损放哪：两个标准位置（以多头为例）

**位置A：信号K线低点下方一到两个跳动（tick）——经典位置。**
逻辑：信号K线是多头宣示控制权的那根K线。价格跌回它的低点之下，说明多头的宣示失败了。
优点：止损近，单手风险小，同样的可亏金额能上更大仓位，盈亏比好看。
缺点：抗噪音能力差。市场经常向下多探一两跳扫掉这批止损再上涨，你会被震出好交易。

**位置B：整个回调摆动低点（swing low）下方一到两跳——宽止损。**
逻辑：只要摆动低点没破，"更高的低点"这个牛市结构就还在，趋势假设未被证伪。
优点：抗噪音，不容易被扫。价格到这里才出场，出得心服口服。
缺点：止损距离远，同样的可亏金额下仓位更小，单笔盈利绝对值变小。

**取舍原则**：信号K线质量极高、位置极佳（比如强趋势中的High 2，信号K线是收在高位的大实体阳线）时，可以用A；信号K线平庸、或市场噪音大（震荡偏多、双向长影线）时，必须用B。**拿不准时用B。** 被扫出一笔本该盈利的交易，对心态的破坏远大于多亏几个跳动。

**空头完全镜像**：卖出后止损放信号K线高点上方一两跳（经典），或整个反弹摆动高点上方一两跳（宽）。

### 3. 三条铁律（违反任何一条，直接回01课重修）

**铁律一：止损是实际挂在交易所的单，不是心理位。**
"心理止损"在真实亏损面前100%失效——价格到位时你会想"再等一根K线看看"，这一等就是大亏。下进场单的同一秒，止损单必须挂上。没有例外。

**铁律二：绝不向亏损方向挪止损。这是头号死罪。**
多单止损只能往上挪，绝不能往下挪。往下挪止损的本质是：理由已被证伪，你却单方面修改证伪标准来保住仓位。这是所有爆仓故事的共同第一章。做CEO你懂这个：KPI没达标就修改KPI的团队，最后死得最惨。

**铁律三：先定止损，再算仓位。永远不反过来。**

```
仓位 = 单笔可亏金额 ÷ 止损距离
```

止损距离由图形结构决定（理由被证伪的位置），可亏金额由资金管理决定（通常为账户的0.25%–1%），仓位是这两者相除的**结果**，不是你的自由变量。先决定"我要做10手"再去找一个塞得下10手的止损位，是本末倒置——那个止损位跟你的入场理由毫无关系，它只是你贪婪的遮羞布。

### 4. 保本止损（Breakeven Stop）陷阱

浮盈一出现就把止损挪到进场价，感觉"这笔稳赚不赔了"——这是心理舒适，不是交易优势。

问题在于：**好趋势的正常回调，深度经常恰好回到突破点/进场区附近再继续原方向。** 也就是说，保本止损放的位置正是市场最爱回踩的位置。结果是一个反复出现的剧本：进场→浮盈→挪到保本→回调扫掉你→趋势按你的方向再走一大段→你在场外。你没亏钱，但你把整套体系里最值钱的那部分利润（趋势段）系统性地送掉了。方程式里的"平均盈利"被砍掉一大块，正期望变负期望。

正确的挪动时机：**等结构给出依据**——出现了新的更高摆动低点，止损跟到那个低点下方。结构没给依据之前，止损待在原地。

由此推出布鲁克斯反复强调的一个结论：**宽止损 + 小仓位，常优于窄止损 + 大仓位。** 两者单笔可亏金额相同（这才是真正的风险），但宽止损的胜率显著更高，因为它给了市场正常呼吸的空间。多数人选窄止损+大仓位，不是因为期望值更好，而是因为大仓位赚起来爽——这是用情绪替代计算。

## 第二部分：出场（Exit）

### 5. 两套出场哲学：Scalp vs Swing

**Scalp（短线固定目标）**：进场前定好一个明确目标价，到了就全部落袋，不恋战。
常用目标：测量移动（measured move）投影位、前高/前低、整数关口（如4500.00）、趋势通道上轨。
特性：胜率高（目标近容易到）、盈亏比低（经常接近1:1甚至更差）。方程式含义：必须靠高胜率撑起期望值，所以**scalp只允许在最高质量的setup上做**，平庸机会做scalp必然长期亏钱。

**Swing（波段跟随）**：不设固定目标，用移动止损（trailing stop）跟着趋势走，直到趋势结构被破坏才离场。
特性：胜率低（很多次被回调震出、小赚小亏收场）、盈亏比高（抓住一次大趋势顶得上多次小亏）。方程式含义：靠大盈亏比撑起期望值，代价是必须忍受连续多笔小亏和"浮盈回吐"的心理煎熬。

两条路都通罗马，走不通的是中间的骑墙者：**用swing的梦想进场，用scalp的胆量持仓**——目标定得很远，浮盈稍有回撤就吓跑，结果承担了swing的低胜率，只拿到scalp的低盈利。这是散户的标准死法。

### 6. 布鲁克斯推荐的结合式：减半 + 移动止损

对本课程的你，默认采用结合式：

1. 进场时挂好止损，仓位按铁律三计算（用偶数手数，方便减半）。
2. **第一目标**（测量移动位或前高）到达时，**平掉一半仓位落袋**，锁定利润、支付这笔交易的"风险成本"。
3. **剩余一半**改用移动止损跟随趋势，博大波段，直到结构破坏离场。

这个设计的妙处在于心理工程：第一笔落袋后，这笔交易大概率已经整体不亏，你拿剩余仓位时心态是"用市场的钱博大的"，能真正拿得住——解决了swing最难的持仓心理问题，同时保留了大盈亏比的可能性。

### 7. 测量移动（Measured Move）：第一目标怎么算

市场的波段常呈对称性：第二段 ≈ 第一段。两种投影法：

**突刺高度投影**：第一段推动（leg 1）的起点到终点的高度，从回调低点向上投影。
例：价格从 4480 一路涨到 4496（第一段高度16点），回调到 4488 后企稳，测量移动目标 = 4488 + 16 = **4504**。

**区间高度投影**：横盘区间的高度，从突破方向投影。
例：区间高点 4500、低点 4490，高度10点。向上突破后目标 = 4500 + 10 = **4510**；若向下突破，目标 = 4490 − 10 = **4480**。

测量移动位不是魔法数字，它有效是因为足够多的机构在那里挂了止盈单。把它当作"第一目标的合理估计"，配合前高、整数关口交叉验证，多个目标聚在一起时最可靠。

### 8. 移动止损（Trailing Stop）具体规则——多头版

拿着剩余半仓时，按以下梯度管理（空头镜像）：

- **常规操作**：每形成一个**更高的摆动低点**（swing low），把止损抬到该低点下方一两跳。这是唯一的常规挪动依据——跟结构，不跟感觉。
- **预警信号**：价格跌破 20EMA 且下方K线有跟随（follow-through，02/03课概念）。不必立刻离场，但提高警觉，收紧对下一个信号的反应速度。
- **警报信号**：出现**强反向K线**（大实体阴线、收在低位、吞没前几根阳线）。趋势的对手盘开始有真实力量了。此时可考虑将止损收得更紧（如该阴线高点上方被反抽失败后离场）。
- **结构破坏 = 离场**：趋势线被跌破，且随后的反抽（回试）形成**更低的高点**（lower high）。"更高的低点+更高的高点"这个牛市定义已死，剩余仓位在反抽失败处出掉，不等止损。
- **Always-in 翻转 = 无条件清仓**：02课的always-in方向从多翻空（连续强阴线+跟随，市场明确易手），不管止损在哪、不管盈亏多少，市价出。always-in翻转后还持多单，等于逆势裸奔。

### 9. 买入高潮（Buy Climax）：在亢奋中离场

**识别**：趋势末端出现连续多根（通常3根以上）**加速放大的大阳线**，实体一根比一根长，几乎无回调、无影线，价格远离20EMA，可能伴随跳空。图形上所有人都在喊"起飞了"。

**本质**：这是趋势中最后的、最不计成本的买盘——踏空者投降追高 + 空头止损被迫回补，两股力量同时耗尽。燃料烧完之后，上方再无买家，随后大概率是剧烈的双向震荡或深度回调。

**应对**：买入高潮是**止盈信号，不是追买信号**。手上有多单：在第二、三根加速大阳线的过程中**主动市价止盈**，不等回落确认——高潮后的回落又快又深，等确认会吐掉大半利润。手上没仓位：什么都不做，绝不追。空仓看着别人狂欢而不动手，是本课要练的核心修养之一。

记住这句话：**业余者在高潮中兴奋加仓，职业者在高潮中把仓位卖给他们。**

### 10. 出场的精神总结

进场靠**理由叠加**（06课会系统化）：趋势方向 + 位置 + 结构 + 信号K线质量，理由越多越敢进。
出场靠**理由消失**：当初让你进场的理由，一个一个反转过来——趋势K线变弱了、更高的低点变成更低的高点了、20EMA失守了、对手盘从无力变有力了——理由消失到临界点，就是离场时。

进出场因此是同一枚硬币：**你不需要一套独立的"出场秘籍"，你只需要诚实地持续回答一个问题——"如果我现在空仓，我还会按原理由进这笔单吗？"答案是否，就出。**

## 第三部分：一笔完整交易演算（ES 5分钟图，多头）

背景设定：标普迷你期货 ES，1点 = 50美元，最小跳动 0.25点（1 tick = 12.5美元）。账户 100,000 美元，单笔风险上限 0.5% = **500美元**。

**第一步：背景与setup（02-04课）**
早盘牛突破，价格从 4490 一路涨至 4506（第一段16点），全程站在20EMA上方，always-in看多。随后两腿回调（ABC）至 **4498.50** 止跌——High 2 setup 成形。第14根K线收出信号K线：阳线，低点 4499.50，高点 4501.75，收在高位。

**第二步：进场单 + 止损单（同时挂）**
- 进场：信号K线高点上方1跳挂买入止损单 → **4502.00** 成交。
- 止损选择：经典位（信号K线低点下方2跳）= 4499.00，距离3点；宽位（摆动低点4498.50下方2跳）= **4498.00**，距离4点。今日盘面双向影线偏多、噪音大 → 选宽止损 4498.00。
- 止损距离 = 4502.00 − 4498.00 = 4点 = **200美元/手**。

**第三步：仓位计算（铁律三）**
```
仓位 = 500 ÷ 200 = 2.5 → 向下取整 = 2手
实际最大亏损 = 2 × 200 = 400美元（占账户0.4%）
```

**第四步：第一目标（测量移动）**
第一段高度16点，从回调低点投影：4498.50 + 16 = **4514.50**。与上方整数关口4515基本重合，目标可信。到4514.50时单手盈利12.5点，风险4点，盈亏比约3:1——期望值检验通过，这笔值得做。

**第五步：持仓管理全过程**
1. 进场后价格涨至 4510，回调至 4504 止跌回升——形成**更高的摆动低点** → 止损从 4498.00 抬到 **4503.50**（4504下方2跳）。此时最坏结果已是整体保本偏盈。
2. 价格触及 **4514.50**，第一目标限价单成交，**卖出1手落袋 +12.5点 = 625美元**。剩余1手继续。
3. 价格涨至 4520 后回调至 4512 止跌——又一个更高摆动低点 → 止损抬到 **4511.50**。剩余仓位最坏也锁定 +9.5点。
4. 随后三根K线连续加速：阳线实体一根比一根大，第三根几乎无影线，价格冲至 4530，远离20EMA——**买入高潮**特征齐备。不等回落确认，**市价 4526 主动止盈剩余1手，+24点 = 1200美元**。

**结算**：总盈利 625 + 1200 = **1825美元**；进场时承担的风险 400美元；实际盈亏比 ≈ 4.6 : 1。注意复盘重点不是赚了多少，而是：每一次挪止损都有结构依据、减仓在预定目标、最终离场有明确信号——**整个过程没有一个决定是拍脑袋的。**

## 常见致命错误清单

1. **不挂实际止损单**，用"心理止损"，价格到位后开始祈祷。
2. **向亏损方向挪止损**——头号死罪，爆仓的标准起手式。
3. **先定仓位再凑止损**：想做大仓，就找个近得不合理的止损塞进去。
4. **浮盈即挪保本**，被正常回调反复扫出，系统性丢掉趋势段利润。
5. **平庸setup做scalp**：低盈亏比+不够高的胜率 = 稳定负期望。
6. **swing的目标、scalp的胆量**：浮盈一回撤就跑，承担低胜率却只拿小利润。
7. **买入高潮中追多/加仓**，在燃料耗尽的最后一根阳线上接盘。
8. **always-in已翻转还死拿**，把"止损没到"当持仓理由。
9. **止损被打后立刻反手报复**，出场决定与下一笔进场决定混为一谈。
10. **进场后才开始想"目标放哪"**——说明进场前方程式根本没算，这笔从一开始就是赌博。

## 看图练习

打开你的交易软件，任选一个品种的5分钟历史图（选已走完的日子，禁止用当天未走完的图）。

**任务：找出3笔完整交易并全程标注。** 每笔必须包含：

1. **背景判断**：趋势还是区间？always-in哪边？（02课）
2. **进场**：是04课的哪个setup？信号K线在哪？标出进场价（信号K线高/低点外一跳）。
3. **止损**：标出经典位和宽位两个候选，写明你选哪个、为什么。
4. **仓位演算**：假设账户10万、单笔风险0.5%，按你的品种合约规格算出仓位（写出算式）。
5. **第一目标**：标出测量移动投影位（写出计算过程），检查是否与前高/整数位重合。

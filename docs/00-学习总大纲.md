# 阿尔·布鲁克斯价格行为学 — 学习总大纲

> 学习方式：只跟教练（Claude）讨论，不看其他老师/课程/资料。
> 唯一的"实验室"是自己的交易软件K线图：教练讲概念 → 我去图上找例子 → 描述给教练 → 教练纠正。
> 每课学完必须**用自己的话复述**，复述正确才进入下一课。每个阶段有**出关标准**，达不到不进阶。

## 核心信条（贯穿全部课程）

1. **没有确定，只有概率。** 理由叠加提高胜率，但永远到不了100%，也不需要。
2. **交易者方程式是唯一裁判**：`胜率 × 盈利 > (1−胜率) × 亏损`，正期望值才做。
3. **进场、止损、出场是同一个决策的三个面**，进场前三者必须全部确定，否则期望值不可计算 = 赌博。
4. **单笔无意义，只有大样本有意义。** 不为一笔盈亏兴奋或沮丧。
5. **真正的优势不在形态，在执行。** 95%的人亏在执行和心态，不亏在知识。

## 学习节奏规则

- 一次只学**一个概念**：讲解 → 复述 → 图上找例子 → 纠正 → 下一个。
- 从 04 课开始，**每学一个进场 setup，必须同时学它配套的止损和目标**，三件事一起学。
- 顺序原则：先思维（01）→ 后识图（02-03）→ 再形态（04-06）→ 最后执行（07-09）。08 可在 04 之后穿插。
- 铁律：07 的样本没跑够、日志没证明正期望，**不许用有意义的资金交易**。
